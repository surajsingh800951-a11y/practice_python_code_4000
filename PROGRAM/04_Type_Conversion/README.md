# 📘 Type Conversion

> Learn how Python automatically converts one data type into another during expressions and operations.

---

# 📖 About

Type Conversion is the process of converting one data type into another automatically while performing operations or expressions in Python.

This chapter helps you understand how different data types interact with each other.

---

# 🎯 Learning Objectives

After completing this chapter, you will be able to:

- Understand Type Conversion
- Convert between numeric data types
- Perform operations on mixed data types
- Understand automatic type conversion
- Check the data type of results

---

# 📚 Topics Covered

- Integer to Float
- Float to Integer
- Integer and Float Operations
- Boolean and Integer Operations
- Mixed Data Type Expressions
- Comparison Operators
- Data Type of Results
