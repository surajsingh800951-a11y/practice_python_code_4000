# 🔄 Type Casting

> Learn how to manually convert one data type into another using Python's built-in type casting functions.

---

# 📖 About

Type Casting is the process of converting one data type into another manually using built-in functions such as `int()`, `float()`, `str()`, `bool()`, `list()`, `tuple()`, and `set()`.

It helps programmers work with different data types efficiently and avoid type-related errors.
