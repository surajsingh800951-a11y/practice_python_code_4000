# 🔀 Conditional Statements (If / Else)

> Learn decision-making in Python using `if`, `elif`, and `else` statements through basic programming concepts and real-life examples.

---

# 📖 About

Conditional statements help a program make decisions based on different conditions. They are one of the most important concepts in Python and are used in almost every real-world application.

---

# 🎯 Learning Objectives

After completing this chapter, you will be able to:

- Write simple `if` statements
- Use `if...else`
- Use `if...elif...else`
- Write nested `if` statements
- Solve logical programming problems
- Build real-life decision-making programs

## 🌍 Real-Life Programs (10)

- [x] Q31. Movie Ticket  
      Agar age 18 ya usse zyada hai → Movie dekh sakta hai.  
      Agar age 12–17 hai → Parent ke saath dekh sakta hai.  
      Agar age 12 se kam hai → Entry nahi milegi.

- [x] Q32. ATM Withdrawal  
      Agar balance ₹5000 ya usse zyada hai → Paise nikal sakte ho.  
      Agar balance ₹1000–4999 hai → Sirf ₹1000 nikal sakte ho.  
      Agar balance ₹1000 se kam hai → Insufficient Balance.

- [x] Q33. Mobile Recharge  
      Agar balance ₹299 ya usse zyada hai → 28 Days Recharge.  
      Agar balance ₹199–298 hai → 14 Days Recharge.  
      Agar ₹199 se kam hai → Recharge nahi ho sakta.

- [x] Q34. Restaurant Bill  
      Agar bill ₹1000 ya usse zyada hai → 20% Discount.  
      Agar bill ₹500–999 hai → 10% Discount.  
      Agar bill ₹500 se kam hai → Koi Discount nahi.

- [x] Q35. Petrol Pump  
      Agar paise ₹500 ya usse zyada hain → Full Tank.  
      Agar paise ₹100–499 hain → Jitna Petrol mile utna bharwao.  
      Agar ₹100 se kam hain → Petrol nahi milega.

- [x] Q36. School Result  
      Marks 90–100 → Grade A  
      Marks 60–89 → Grade B  
      Marks 35–59 → Grade C  
      Marks 35 se kam → Fail

- [x] Q37. Shopping Mall  
      Agar Shopping ₹5000 ya usse zyada hai → Free Gift.  
      Agar ₹2000–4999 hai → 10% Discount.  
      Agar ₹2000 se kam hai → Koi Offer nahi.

- [x] Q38. Bus Ticket  
      Age 60 ya usse zyada → Senior Citizen Discount.  
      Age 5–59 → Full Ticket.  
      Age 5 se kam → Free Ticket.

- [x] Q39. Internet Data  
      Data 2 GB ya usse zyada → HD Video dekho.  
      Data 500 MB–2 GB → Normal Video dekho.  
      Data 500 MB se kam → Sirf Browsing karo.

- [x] Q40. Ice Cream Shop  
      Agar paise ₹100 ya usse zyada hain → Chocolate Ice Cream.  
      Agar paise ₹50–99 hain → Vanilla Ice Cream.  
      Agar paise ₹50 se kam hain → Ice Cream nahi milegi.
