# 📋 Tuples

> Learn how to store and access multiple values using Python Tuples.

---

# 📖 About

A Tuple is one of Python's built-in data structures used to store multiple values in a single variable. Tuples are ordered, immutable (cannot be changed after creation), and allow duplicate values.
