# 🔁 For Loop

> Learn how to execute a block of code repeatedly using Python `for` loops.

---

# 📖 About

The `for` loop is one of the most commonly used looping statements in Python. It is used to iterate over sequences such as numbers, strings, lists, tuples, and more. It helps reduce repetitive code and is essential for solving programming problems.
