# 📖 About

The `for` loop is used to repeat a block of code multiple times. It is one of the most important concepts in Python and is widely used for counting, calculations, patterns, strings, numbers, and problem solving.

This chapter contains **188 practice questions**, starting from basic `for` loop programs and gradually moving toward advanced logic challenges.

---

# 🎯 Learning Objectives

After completing this chapter, you will be able to:

- Write basic `for` loops
- Use `range()` effectively
- Work with increasing and decreasing sequences
- Use conditions inside loops
- Perform calculations using loops
- Take repeated input from users
- Find sums, products, maximum and minimum values
- Create star and number patterns
- Work with alphabets and ASCII values
- Process strings using loops
- Process individual digits of numbers
- Solve prime, factor and special-number problems
- Generate Fibonacci and mathematical series
- Use nested `for` loops
- Solve logical programming challenges
