# 📋 Lists

> Learn how to store, access, update, and manipulate multiple values using Python Lists.

---

# 📖 About

A List is one of the most commonly used data structures in Python. It allows you to store multiple values in a single variable. Lists are ordered, mutable, and can contain duplicate elements.

- Create Lists

- Add and Remove Elements
